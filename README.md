# Бронирование жилья

Лабораторная работа № 1 по прикладному программированию.
Вариант 8: классы для предметной области бронирования жилья.

Цель проекта — изучить ООП в Python, обработку исключений и хранение
связанных объектов в JSON и XML.

## План разработки

1. Описать проект и требования.
2. Реализовать классы предметной области и проверку значений.
3. Добавить CRUD и правила бронирования.
4. Реализовать чтение и запись JSON и XML.
5. Добавить консольный интерфейс и демонстрационные данные.
6. Проверить основные сценарии и обработку ошибок.
7. Актуализировать UML и инструкцию запуска.

Отчёт оформляется отдельно после завершения репозитория.
